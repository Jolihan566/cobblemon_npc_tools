⚡ Cobblemon Spawn Generator
A visual datapack editor for configuring where and how Pokémon spawn in your Cobblemon world.
This tool lets you create, edit, and export custom Cobblemon spawn datapacks without writing raw JSON. You can configure spawn biomes, conditions, rarity buckets, drop overrides, herd spawns, and full custom Pokémon — all exported as a ready-to-drop .zip datapack.
💡
Everything is saved in your browser session. Use Export Datapack often to save your progress as a local file.
✦ What you can do
Feature Description
Spawn Entries Define where each Pokémon spawns — biomes, time of day, weather, light level, and more.
Herd Spawns Create group spawns where a leader and filler members appear together.
Drop Overrides Override default Cobblemon drops per Pokémon, including setting empty drops to suppress all loot.
Custom Pokémon Define entirely new Pokémon with stats, moves, evolutions, and species files for fakemon.
Bulk Apply Apply spawn settings to many Pokémon at once — all visible, selected, or by category.
Biome Browser Browse all Cobblemon biomes and see which Pokémon you've configured to spawn there.
Import Load an existing spawn datapack .zip to continue editing it.

⚡ Quick Start
Get your first spawn datapack exported in under 5 minutes.
1
Name your pack — Type a name in the top-left input (e.g. my-spawn-pack). This becomes the exported zip filename and folder structure.
2
Find a Pokémon — Use the sidebar search or type filters to find the Pokémon you want. Click it to select it.
3
Add a spawn entry — Click + Spawn Entry in the editor header. A new entry appears with default values.
4
Set a biome — In the spawn entry's Condition section, type a biome tag like #cobblemon:is_forest in the Biomes field, or use the Tag Picker button to browse available tags.
5
Adjust rarity — Set the Bucket (common / uncommon / rare / ultra-rare) and Weight to control how often it spawns relative to others in the same bucket.
6
Check the Preview — The right panel shows the exact JSON that will be exported. Switch to the Spawn tab to see it.
7
Export — Click 📦 Export Datapack in the topbar. A .zip is downloaded. Drop it into your Minecraft datapacks/ folder and reload the world.
⚠
Cobblemon datapacks require a world reload (not /reload) to take effect. Return to the main menu and re-open your world after placing the datapack.

🌿 Spawn Entries
Each spawn entry defines one way a Pokémon can appear in the world.
A single Pokémon can have multiple spawn entries — for example one for forests during the day, another for caves at night, and a fishing entry for rivers. Each entry is exported as its own object inside the spawns array.
Core Fields
Bucket
Rarity tier. common uncommon rare ultra-rare. Cobblemon fills each bucket separately — a rare Pokémon only competes with other rare Pokémon for its slot.
Context
Where in the world the Pokémon can physically appear. grounded = on land surface. submerged = underwater. surface = on water surface. fishing = catchable via fishing rod.
Weight
Relative spawn probability within its bucket. Higher weight = more frequent. E.g. Magikarp might have weight 15 while Gyarados has weight 2 — both in the same bucket.
Level Range
Min and max level the Pokémon can spawn at, e.g. 5-40.
Presets
Comma-separated preset names that apply additional spawn detail rules. See the Presets page for the full list.
Entry ID
Each entry has a unique string ID used internally by Cobblemon. It's auto-generated as pokemonid-1, pokemonid-2, etc. You can rename it if you need to reference it elsewhere (e.g. for spawn detail presets).
Weight Multiplier
Optionally multiplies the entry's weight under a specific condition (e.g. multiply by 5 when it's raining). Set the multiplier value and pick the condition (isRaining / isThundering).
Validation Warnings
Entries with issues (missing biomes, invalid level ranges, etc.) show a ⚠ badge in the entry header. Hover the badge to see the specific warning.
💡
Use the ⎘ Copy From button to clone spawn entries from another Pokémon — great for evolution lines that share the same habitat.
💡
Use ⬆ Evo Line to automatically scale spawn data across an entire evolution line — base forms spawn more frequently, final evolutions less.
🔎 Conditions
Conditions restrict where and when a spawn entry is valid.
Each spawn entry has a Condition (spawn where this is true) and an optional Anti-Condition (do NOT spawn where this is true). Both work identically, just with opposite logic.
Condition Fields
Biomes
One biome or biome tag per line. Can be a specific biome ID like minecraft:forest or a tag like #cobblemon:is_forest. Tags are prefixed with #.
Dimension
Optional. Comma-separated dimension IDs to restrict spawning, e.g. minecraft:overworld.
Min/Max Sky Light
0–15. Sky light is the direct sunlight value — 15 outdoors in daylight, 0 underground. Useful for cave spawns (maxSkyLight: 0) or surface-only spawns (minSkyLight: 7).
Min/Max Light
0–15. Total light level (sky + block light combined).
Time Range
Restricts to a Minecraft time of day. Values: day, night, dawn, dusk, or a numeric range like 0-6000.
Moon Phase
0–7. Restricts to a specific moon phase (0 = full moon).
Can See Sky
When checked, the spawn point must have an unobstructed view of the sky.
Is Raining
Only spawn during rain.
Is Thundering
Only spawn during thunder storms.
Needed Nearby Blocks
One block ID per line. At least one of these blocks must be within range of the spawn point.
Needed Base Blocks
One block ID per line. The block directly under the spawn point must be one of these.
💡
For cave-dwelling Pokémon: set maxSkyLight: 0 and use #cobblemon:is_cave biome tag. For surface-only: set canSeeSky: true.
Common Condition Patterns
Pokémon type Typical condition setup
Surface grass Biome: #cobblemon:is_overworld, canSeeSky: true, context: grounded
Cave dweller maxSkyLight: 0, minLight: 0, maxLight: 7, context: grounded
Aquatic Biome: #cobblemon:is_ocean or #cobblemon:is_river, context: submerged
Night only timeRange: night, context: grounded
Rain only isRaining: true
Nether Dimension: minecraft:the_nether, biome: #cobblemon:is_nether
🌍 Biomes & Tags
How to target specific biomes or groups of biomes.
Cobblemon uses Minecraft's biome tag system. You can target a single biome by its ID, or a whole category of biomes using a tag.
Biome ID Format
minecraft:forest minecraft:plains minecraft:desert
A specific biome ID. The Pokémon will only spawn in that exact biome.
Biome Tag Format
#cobblemon:is_forest #cobblemon:is_ocean #cobblemon:is_overworld
Tags (prefixed with #) match any biome in that group. Cobblemon provides many useful tags — use the Tag Picker button inside a spawn entry or the Biome Browser to see them all.
Common Cobblemon Tags
Tag Matches
#cobblemon:is_overworld All overworld biomes
#cobblemon:is_forest Forest-type biomes
#cobblemon:is_plains Plains and meadow biomes
#cobblemon:is_ocean All ocean biomes
#cobblemon:is_river River biomes
#cobblemon:is_mountain Mountain biomes
#cobblemon:is_desert Desert biomes
#cobblemon:is_jungle Jungle biomes
#cobblemon:is_swamp Swamp biomes
#cobblemon:is_snowy All snowy biomes
#cobblemon:is_cave Cave/underground biomes
#cobblemon:is_nether All Nether biomes
#cobblemon:is_end End biomes
For a full tag list, visit the Spawn Condition wiki page or use the Tag Picker inside the tool.
Tag Picker
Click the # Tag Picker button next to the Biomes field in any spawn entry. This opens a searchable list of all known Cobblemon biome tags. Select one or more and click ✓ Add Selected to insert them.
🐾 Herd Spawns
Group spawns where multiple Pokémon appear together.
A herd spawn creates a group of Pokémon instead of a single one. One Pokémon is the leader and the rest are filler members that fill up the herd to its max size. Members can be different Pokémon species.
Creating a Herd Entry
1
Click 🐾 Add Herd in the editor header to add a herd-type spawn entry.
2
Set Spawn Position (grounded / submerged / surface), Bucket, and Weight as normal.
3
Set Max Herd Size — the maximum total number of Pokémon in the group.
4
Set Min Distance Between Spawns — how spread out members are (in blocks).
5
Add Herd Members — click + Add Member. Each member has a Pokémon ID, max times it can appear, and an optional level range offset from the herd's base level.
Herd Member Fields
Pokémon ID
The internal Cobblemon ID (lowercase, no spaces). E.g. rattata, bidoof.
Max Times
How many of this member can appear in one herd. Leave blank for unlimited.
Is Leader
Marks this member as the herd leader — the first to spawn. Only one leader per herd.
Level Offset
Shifts the member's level relative to the herd's base range. E.g. +5 means this member is 5 levels higher.
💡
Use Bulk Apply → 🐾 Herd Spawn tab to apply herd settings to many Pokémon at once — great for early-game common Pokémon like Rattata or Pidgey.
✦ Bulk Apply
Apply spawn settings to many Pokémon at once.
The Bulk Apply modal adds spawn entries to multiple Pokémon simultaneously. It targets either your batch-selected Pokémon (Ctrl+click in the sidebar) or all currently visible Pokémon if none are selected.
Normal Spawn Bulk Apply
Fills in the standard spawn entry fields (bucket, context, weight, level range, biomes, sky light, time range, weather conditions) and adds that entry to all targets. Check Replace all existing to overwrite instead of append.
Herd Spawn Bulk Apply
Same as normal, but creates herd entries. Each target Pokémon is automatically added as both leader and a filler member using its own ID. You can customise member templates before applying.
Quick-Action Bar
The bar below the editor header has one-click actions for common tasks:
◎ Legendaries
Toggle preset ultra-rare spawns on/off for all Legendary Pokémon.
◎ Mythicals
Toggle preset ultra-rare spawns for all Mythicals.
◎ Ultra Beasts
Toggle preset ultra-rare spawns for all Ultra Beasts.
⬆ Set Rarity
Force all existing spawn entries for Legendaries/Mythicals/UBs to ultra-rare bucket.
🗑 Clear All
Remove ALL spawn data from every Pokémon — use with caution.
🎁 Drop Overrides
Customise what items a Pokémon drops when defeated.
Cobblemon has its own drop system that differs from vanilla Minecraft. Instead of a loot table, it uses a roll amount plus a list of entries. For each kill, Cobblemon picks up to amount entries by rolling each one's percentage chance. See the Species wiki page for full details.
How Drops Work
1
Cobblemon tries to collect amount successful drops from the entries list.
2
For each entry, it rolls a percentage check. If it passes, that entry counts toward the amount target.
3
Once amount entries pass, or all entries have been rolled, rolling stops.
4
All passing entries drop their item (with a random quantity in range).
Drop Entry Fields
Item ID
Minecraft or Cobblemon item ID, e.g. minecraft:bone or cobblemon:poke_ball.
Min / Max Qty
How many of the item to drop (random between min and max).
% Chance
Percentage probability this entry passes its roll. 100 = always, 50 = half the time. Also adjustable via the slider.
Roll Amount
The Roll Amount field controls how many entries Cobblemon attempts. Setting it to 0 effectively disables all drops. Setting it higher than the number of entries means Cobblemon will roll all entries every time.
Empty Drops (Suppress All)
Toggle Empty drops to export a species file with amount: 0, entries: []. This completely suppresses the Pokémon's default Cobblemon drops — useful if you want a Pokémon to drop nothing, or if you're replacing drops with a different system.
Presets & Bulk Operations
⚡ Presets menu
Quick-apply common drop templates: Bone, String, Seeds, Feather, Slimeball, or Fish+Scales combo.
🚫 No Drops
Sets empty drops in one click.
🗑 Set Empty (all visible)
Applies empty drops override to every Pokémon currently visible in the sidebar.
✕ Clear All (all visible)
Removes all drop overrides from visible Pokémon, reverting them to Cobblemon defaults.
💡
Drop overrides export as species_additions/ files — they only override the drops field, leaving all other species data (stats, moves, etc.) untouched.
✦ Custom Pokémon
Create entirely new Pokémon species for fakemon or custom regions.
Custom Pokémon are written as full species/ JSON files — not additions. This means they define the entire Pokémon from scratch. Once created, they appear in the sidebar under a purple separator and can have spawn entries and drop overrides configured like any other Pokémon.
Creating a Custom Pokémon
1
Click ✦ Custom Pokémon in the topbar to open the creation modal.
2
Enter a Display Name — the ID auto-generates from it (you can override it). The ID must be unique, lowercase, no spaces.
3
Set the Primary Type (required) and optionally a Secondary Type.
4
Fill in the remaining tabs: Stats (base stats, EVs, size), Moves, Evolutions, and Misc (lighting, drops).
5
Click ✦ Save Pokémon. It appears at the bottom of the sidebar with a purple border.
6
Select it in the sidebar to add spawn entries as normal.
Identity Tab
Display Name
The in-game name shown to players.
Internal ID
Used for file names, spawn IDs, and evolution result references. Must be unique and lowercase.
Types
Primary (required) and secondary (optional) types.
Catch Rate
0–255. Higher = easier to catch. Legendaries typically use 3–45, common Pokémon 100–255.
Male Ratio
0.0–1.0 (probability of being male). Use -1 for genderless Pokémon.
Experience Group
Determines how fast the Pokémon levels up: erratic, fast, medium_fast, medium_slow, slow, fluctuating.
Egg Groups
Comma-separated. E.g. field, monster. Used for breeding compatibility.
Abilities
Ability 1, Ability 2 (optional), Hidden Ability (use h:abilityname format).
Stats Tab
Set all 6 base stats (HP, Atk, Def, SpA, SpD, Spe). The BST (Base Stat Total) updates live with a visual bar chart. Also set EV yields and physical size (height in decimeters, weight in hectograms, base scale, hitbox dimensions).
Moves Tab
Add moves by learning method. Format: method:movename — all lowercase, no spaces in the move name.
Method Example Notes
Level-up 5:quickattack Number before colon = level learned
Egg egg:thunder Inherited from parent on hatch
TM tm:thunderbolt Learnable via TM item
Tutor tutor:icebeam Learnable from move tutor
Evolutions Tab
Variant
The evolution trigger type: level_up, item_interact, trade, friendship, use_move, etc.
Result Pokémon
The internal ID of the Pokémon this evolves into.
Required Context
For item evolutions, the item ID e.g. cobblemon:fire_stone.
Level
For level_up evolutions, the minimum level required.
Consume Item
Whether the held/used item is consumed on evolution.
Misc Tab
Configure lighting data (light level 0–15 and glow mode), flags (shoulder mountable, cannot dynamax), and custom drops that are baked into the species file itself.
⚠
Custom Pokémon need a corresponding model and texture to actually render in-game. This tool only generates the data files. Use Cobblemon's Fakemon Generator or Blockbench with the Cobblemon plugin for models.
🔍 Filters & Search
Find Pokémon quickly using search, status filters, generation filters, and type filters.
Search Bar
Searches by Pokémon name, Pokédex number, or type name simultaneously. Searching fire will show all Fire-type Pokémon; searching 25 will show Pikachu.
Status Filters
All
Show all Pokémon (default).
Has Spawn
Only Pokémon that have at least one spawn entry configured.
No Spawn
Pokémon without any spawn entries — useful for finding gaps in coverage.
Cobblemon
Only Pokémon implemented in base Cobblemon.
Mega
Only Mega evolutions (requires Mega Showdown addon).
Not Impl.
Pokémon not yet in Cobblemon — listed but not in-game.
✦ Custom
Only your custom / fakemon Pokémon.
Generation Filters
G1–G9 buttons filter by Pokédex generation. Only one generation filter can be active at a time (but you can combine with status/type filters).
Type Filters
Click any of the 18 type badges to filter by type. Multiple types can be active at once. The ANY / ALL toggle controls the mode:
ANY (inclusive)
Shows Pokémon that have at least one of the selected types. E.g. Fire + Water shows all Fire-types and all Water-types.
ALL (exclusive)
Shows only Pokémon that have every selected type. E.g. Fire + Flying shows only dual Fire/Flying Pokémon like Charizard.
Multi-select
Ctrl+click (or ⌘+click on Mac) to batch-select Pokémon. Selected Pokémon are highlighted in blue. The ☑ Select All Visible button selects everything currently showing in the list. Batch-selected Pokémon are the targets of Bulk Apply.
🗺 Biome Browser
See which Pokémon spawn in each biome and visualise coverage.
Open with 🌍 Biome Browser in the topbar. The left panel lists all Cobblemon-defined biomes grouped by category. Click a biome to see all Pokémon you've configured to spawn there.
Spawn List Filters
The right panel has filter buttons to show only spawns of a specific bucket (common, rare, etc.) or context (grounded, submerged, etc.).
Coverage Heatmap
Click ▦ Coverage Heatmap in the Biome Browser toolbar. Each biome shows a colour-coded tile based on how many Pokémon spawn there:
● 0 — No coverage ● 1–4 — Low ● 5–12 — Medium ● 13+ — High
Click any tile to jump to that biome in the spawn list. Use Grid / List toggle and sort by Count, A–Z, or Category.
📦 Export & Import
Download your datapack and load existing ones.
Exporting
Click 📦 Export Datapack. A .zip is downloaded containing:
my-pack.zip ├── pack.mcmeta └── data/ └── cobblemon/ ├── spawn_pool_world/ ← one .json per Pokémon with spawns ├── species_additions/ ← drop overrides for existing Pokémon └── species/ ← full species files for custom Pokémon
⚠
Place the unzipped folder in saves/[world]/datapacks/. Then reload the world from the main menu — /reload does not work with Cobblemon datapacks.
Importing
Click 📂 Import and select a previously exported .zip. The tool reads all spawn files and species additions and loads them into the editor so you can continue editing and re-export.
💡
Import works with datapacks exported by this tool or hand-written ones that follow standard Cobblemon spawn file format.
⚙ Pack Settings
Configure metadata and advanced options for your datapack.
Pack Identity
Pack Name
Used as the exported zip filename. Synced with the topbar input.
Description
Written into pack.mcmeta — shown in Minecraft's datapack list.
Namespace
Folder name under data/. Defaults to cobblemon. Only change if you know what you're doing.
Negate Base Spawns
When enabled, a filter block is added to pack.mcmeta that blocks all of Cobblemon's default spawn files. Only your configured spawns will be used. Use this for custom regions or servers with fully custom spawn tables.
⚠
Any Pokémon you haven't configured will not spawn at all when this is enabled. Make sure you've set up all desired spawns before enabling.
Mod Compatibility
Needed Installed Mods
Comma-separated mod IDs. Spawns only apply if these mods are installed. E.g. biomesoplenty.
Needed Uninstalled Mods
Spawns only apply if these mods are not installed — useful for fallback spawns when a biome mod is absent.
📊 Buckets & Weights
How Cobblemon decides which Pokémon to spawn.
Cobblemon uses a bucket-based system — each spawn attempt picks a bucket first, then picks a Pokémon within that bucket. Rare Pokémon never compete directly with common ones.
Buckets
Bucket Typical usage Suggested weight
common Frequent encounters, starter areas 5–15
uncommon Less frequent but expected encounters 3–8
rare Uncommon finds, version-specific Pokémon 1–5
ultra-rare Legendaries, very rare spawns 0.1–2
Weight
Within a bucket, each Pokémon's chance is weight ÷ sum of all weights in bucket. Rattata at weight 10 and Pikachu at weight 2 in common means Rattata is 5× more likely when a common slot opens.
📋 Presets
Named spawn detail configurations provided by Cobblemon.
Preset Description
natural Spawns on natural terrain — grass, dirt, stone. Most surface Pokémon use this.
wild General wild Pokémon — no block requirement. Less restrictive than natural.
water Water-dwelling — applies water-surface tags and related conditions.
fishing Can be caught with a fishing rod.
cave Cave-dwelling — applies underground conditions.
legendary Legendary settings — very low weight, open-world conditions.
💡
You can stack presets with commas: natural, wild. See the Spawn Detail Presets wiki page for the full list.

The raw file formats that get exported.
Spawn Pool World File
Path: data/cobblemon/spawn_pool_world/pokemonid.json
{ "enabled": true, "spawns": [ { "id": "bulbasaur-1", "pokemon": "bulbasaur", "type": "pokemon", "bucket": "common", "context": "grounded", "weight": 10.0, "level": "5-25", "presets": ["natural"], "condition": { "biomes": ["#cobblemon:is_forest"], "timeRange": "day", "canSeeSky": true } } ] }
Species Additions File
Path: data/cobblemon/species_additions/pokemonid.json
{ "pokemon": "bulbasaur", "drops": { "amount": "1", "entries": [ { "item": "minecraft:vine", "quantityRange": "1-2" }, { "item": "cobblemon:miracle_seed", "quantityRange": "1", "percentage": 25 } ] } }

Path: data/cobblemon/species/pokemonid.json — complete Pokémon definition. See Species wiki for the full spec.
